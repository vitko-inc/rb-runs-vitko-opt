# rb-runs-vitko-opt

Run repository for the open runner benchmark: [vitko-inc/runner-benchmark](https://github.com/vitko-inc/runner-benchmark).

The workflows here are copied from that repository at commit `f3d35928355f83fabbb3d7a5cf7b41e2316b403a`. Every benchmark run of one provider happens in this repository, so its run IDs and job logs can be checked on GitHub. The method, the suite and the results live in the main repository.
